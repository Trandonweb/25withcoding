Firebase 관리자 계정으로 인증합니다. GitHub 토큰은 Cloudflare Worker Secret에 보관되며 이 브라우저로 전달되지 않습니다. 편집을 멈추면 make_main/page1.json, page2.json…에 자동 저장됩니다.
