관리자 검토 대기

시간IP 주소감지 내용요청 경로검토
검토 대기 항목이 없습니다.서버 연결 후 수집된 이벤트를 관리자가 직접 검토할 수 있습니다.
접속 URL은 개인정보 보호를 위해 경로만 저장하며 쿼리 문자열과 프래그먼트는 수집하지 않습니다. 동일 IP 요청 횟수는 최근 90일간 보안 서버에 수집된 이벤트 기준입니다. 일부 브라우저가 문서 응답 코드를 제공하지 않으면 응답 코드는 '미수집'으로 표시됩니다. IP 차단은 관리자 수동 처리만 가능하며 자동 차단은 사용하지 않습니다.

IP 영구 차단

입력한 IP는 Cloudflare 연결 후 서버 차단 목록에 등록됩니다. 자동 차단은 수행하지 않습니다.
