25WITHCODING 보안 접속 기록 안내

사이트의 계정과 서비스, 구성원의 이용 환경을 보호하고 비정상적인 접근을 확인하기 위해 아래 정보를 처리할 수 있습니다.

수집하는 정보

  • 접속 IP 주소와 접속 시각
  • 접속한 페이지 경로 및 HTTP 요청 방식
  • Cloudflare가 제공하는 국가·지역·도시 추정치, ASN 및 네트워크 사업자 정보
  • 브라우저 User-Agent 정보와 이를 바탕으로 구분한 브라우저 종류, 운영체제, 기기 유형
  • 브라우저에 무작위로 발급한 Device ID
  • 로그인한 경우 Firebase UID, 학번 계정 식별자 및 보안 세션 ID

수집하지 않는 정보

  • GPS 위치, 하드웨어 일련번호, 기기의 실제 고유 하드웨어 ID
  • 비밀번호 및 Firebase ID Token 원문
  • 입력한 비밀번호, 폼 내용, 메시지 내용
  • URL의 검색어(query string)와 페이지 fragment
  • 화면 크기나 글꼴 목록을 이용한 상세 브라우저 지문

이용 목적

  • 비정상 접속 및 서비스 오남용 확인
  • 기기·계정·세션·IP 단위 접근 제한 관리
  • 보안 사고 조사 및 관리자 조치 이력 확인

보관 기간

  • 상세 접속 기록: 수집 시점부터 90일
  • 기기 프로필: 마지막 활동 이후 최대 180일
  • 보안 세션: 최대 1시간, 활동 중 갱신
  • 차단 기록: 관리자가 해제할 때까지
  • 관리자 조치 감사 기록: 90일

정확성 및 주의사항

IP를 이용한 위치·통신사 정보는 추정치이며 VPN, 이동통신망, 공용 Wi-Fi 등에 따라 실제 위치나 이용자를 나타내지 않을 수 있습니다. Device ID는 브라우저에 저장되는 무작위 식별자이므로 실제 기기 자체를 식별하는 하드웨어 ID가 아닙니다.

접속 기록은 보안 목적으로 제한된 관리자만 확인하도록 설계됩니다. 문의나 정정 요청은 사이트 운영 관리자에게 전달해 주세요.

이 안내는 보안 게이트웨이가 실제 운영 환경에 적용될 때 효력이 발생하도록 준비한 문서입니다. 운영 적용 전 학교의 개인정보 처리 기준과 담당 교사의 확인이 필요합니다.
