PHASE 01 · PIXEL DATA

이미지를 픽셀 데이터로.

이미지를 작은 픽셀 격자로 변환하고, 각 픽셀에 번호를 붙여 HEX 색상으로 저장합니다. 이미지 한 장은 엔트리 작품의 리스트 하나로 보관됩니다.

01 · 이미지 가져오기

이미지를 선택하면 원본 비율을 유지하며 가로 픽셀 수를 기준으로 변환합니다. 16:9 이미지는 기본적으로 160 × 90 픽셀이 됩니다.

※ 원본 이미지는 브라우저 안에서 처리됩니다. 업로드 서버로 전송하지 않습니다.

02 · 픽셀 미리보기

확대해서 보여주지만 실제 저장 데이터는 작은 픽셀 격자입니다.

이미지를 선택한 뒤 변환해 주세요.
대기 중

03 · 학습 데이터 보관함

보관함의 이미지 하나가 엔트리 리스트 하나가 됩니다. 리스트에는 1번 픽셀부터 마지막 픽셀까지 번호와 HEX 색상이 차례대로 저장됩니다.

아직 보관된 이미지가 없습니다.
엔트리 작품 파일 만들기

보관한 이미지가 각각 별도의 리스트로 들어갑니다.

저장 구조
각 리스트 항목: 픽셀번호|#RRGGBB
예: 1|#FFFFFF, 2|#33CC77 …
픽셀의 가로·세로 크기는 리스트 이름에 함께 기록됩니다.
