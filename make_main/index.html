GitHub 저장 설정

JSON 파일은 저장소에 커밋됩니다. 저장할 때만 권한이 있는 토큰을 입력하세요.

토큰은 이 화면의 메모리에만 유지되며 localStorage나 JSON 파일에 저장하지 않습니다. GitHub의 Trandonweb/25withcoding 저장소만 대상으로 하고, Contents 권한을 읽기 및 쓰기로 설정하세요.
